# Ecopontos Service

**Responsabilidade:** cadastro e busca geoespacial de pontos de entrega
voluntária de recicláveis, filtráveis por material aceito.

**Dado próprio:** PostgreSQL com extensão PostGIS para consultas geoespaciais
(distância, bounding box).

**Contrato:** `GET /ecopontos?material=`.

**Status:** esqueleto — código em `src/`, implementação prevista para a Etapa 2.
